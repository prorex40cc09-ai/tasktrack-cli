# TaskTrack CLI

TaskTrack CLI is a simple command-line task manager written in Java.

This project exists mainly to practice GitHub workflows including:

- commits
- branches
- pull requests
- issues
- GitHub Actions
- releases
- tags

## Features

- Add tasks
- List tasks
- Complete tasks
- Delete tasks
- Save tasks to a file

## Project Structure

src/main/java/com/tasktrack
Main.java
Task.java
TaskManager.java
FileStorage.java

## Compile

javac src/main/java/com/tasktrack/*.java

## Run

java com.tasktrack.Main
